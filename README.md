## Featured Projects

### <img src="https://api.iconify.design/tabler/rocket.svg?color=%238b949e" width="22" height="22" align="center" /> [Lorentzburn](https://github.com/SamGon24/lorentzburn)
A spaceship-themed Battleship game inspired by *The Expanse*. Framework-agnostic TypeScript game engine in an npm-workspaces monorepo with a React + Tailwind frontend. `TypeScript` `React` `Tailwind` `Vite` `Vitest`
